# 微信读书终端阅读器

项目正在按本地票据逐步实现。目前支持扫码登录、书架目录、图文阅读与上下章切换，并提供基于 XHTML/CSS 的图形书页。

## 安装与运行

需要 Python 3.12+ 和 uv。Python 依赖安装在项目的 `.venv` 中。

图形排版额外需要系统 Pango：在 macOS 使用 `brew install pango` 安装。程序仅为图形子进程补充 Homebrew 库搜索路径，不修改 shell 配置。

```bash
uv sync --dev
uv run weread --help
uv run weread
```

也可使用 `uv run python -m weread_tui`。首页按 `?` 显示或隐藏帮助，按 `q` 退出。

## 登录

点击「扫码登录」，用本人微信扫码并确认；手机要求四位验证码时在终端输入。二维码过期可点击「重新扫码」，Esc 取消尚未完成的扫码。

首页分别显示网页会话和官方 API Key 的状态。扫码后自动尝试获取官方密钥；缺少密钥时，先在微信读书 App 的设置中开通微信读书 Skill，再重新扫码，或通过「补充 API Key」的隐藏输入框填写。

凭据只写入 macOS Keychain；无法使用 Keychain 时会提示仅保留本次会话。重启时重新验证已保存的凭据；网络不可达时显示「待验证」，不误报过期。不支持的平台不使用文件保存凭据。

## 阅读

点击「打开书架」，使用 j/k 或方向键移动，Enter 选书。Tab 切换到目录，再按 Enter 打开章节。书架中的有声书与文章收藏会显示，但暂不支持阅读。

正文使用当前账号网页会话获取，必须在官方网页端具有阅读权限。阅读时使用 j/k 滚动、[ / ] 上下章切换、r 重新加载，Esc 或 q 返回目录；书架中的 r 刷新书架，Esc 或 q 返回首页。

图片从章节资源包或允许范围的图片地址获取，按原文顺序显示并缓存在 `~/.cache/weread-tui/resources/`。失败时保留正文并显示缺图原因，不表示完整加载成功。

正文加载后，支持图像协议的终端可按 g 打开图形书页，h/l 或左右方向键翻页，Esc 返回文字。书页使用原始 XHTML、可用的原书 CSS 和缓存图片；其他文档指定的文件与网络资源不自动加载，原书样式不可用时使用默认排版。图形视图中使用 `+/-` 调整字号（16–28，`=` 也可放大），`Shift+↑/↓` 调整行距（1.2–2.0）；首次调整以原显示页首个正文字符定位，连续调整沿用该字符，主动翻页后重新定位；无法准确定位时保留原页并提示。快速调整期间顶部显示目标参数，完成后显示实际参数；达到上下限时提示。窗口尺寸及终端字体像素变化会自动重排；连续调整采用防抖并保留阅读字符，旧任务不会覆盖新页。排版失败后保留提示，再次调整可重试；Esc 返回会清理书页与渲染进程。

## 阅读位置与离线恢复

本地记录保存在 `~/.local/share/weread-tui/progress.sqlite3`，按账号、书籍、章节及正文版本隔离，保存字符锚点而非页码。翻页成功和主动切章后立即提交，正常返回或退出无需额外保存；邻页预加载不阻塞保存。

重启并在书架选中有记录的书，会自动打开上次章节及图形阅读位置。字号、行距或窗口变化后恢复到包含原字符的页，恢复及重排不刷新实际阅读时间。若正文版本或布局已无法匹配，会明确提示并保留旧记录；此时从章首显示，继续翻页会保存当前版本的新位置。

打开书籍时只读查询云端进度，按实际阅读时间选择较新的记录，并显示采用本地还是云端位置；同时间、时间缺失或不可比较时保留本地。云端坐标按完整原文的 UTF-16 偏移转换；无法访问或准确定位时提示原因，有本地记录则回退，不提交云端进度或阅读时长。

已读取的书架、目录、正文和样式按账号缓存在 `~/.cache/weread-tui/reading/`。断网时可通过这些缓存恢复本地阅读；未缓存内容仍需联网，明确的权限拒绝不会用缓存绕过。新的云端坐标必须用联网获取的正文验证。

当前图形阅读保存精确字符位置，主动进入文字诊断章节时记录章首；文字滚动位置恢复、排版设置持久化仍在后续票据中。

## 开发与验证

```bash
uv run pytest
uv run mypy
uv build
```

代码位于 `src/weread_tui/`，行为测试位于 `tests/`，使用 pytest、pytest-asyncio 和 Textual Pilot。命令行测试调用已安装入口，界面测试模拟真实按键。采用四空格缩进、描述性命名及中文注释，保持实现简单。

## 当前实现边界

首版目标是支持原生 Ghostty 上的微信读书图形阅读；EPUB 后续接入。进度功能仅从云端读取并保存本地位置，不提交阅读时长。协议独立实现，不复制或移植参考项目源码。
